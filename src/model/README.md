# ROADMAP-MODETL


## 1. Supervised learning (обучение с учителем): есть правильные ответы

| Задача | Атрибут: что на выходе | Методы | Примеры |
|---|---|---|---|
| **Classification (классификация)** | Категория из заранее заданного списка | Logistic Regression (логистическая регрессия), k-NN (k ближайших соседей), Naive Bayes (наивный Байес), Decision Tree (дерево решений), Random Forest (случайный лес), Gradient Boosting (градиентный бустинг: XGBoost, LightGBM, CatBoost), SVM (метод опорных векторов), нейросети | Спам / не спам, кот / собака, отток клиента, диагноз по анализам |
| **Regression (регрессия)** | Непрерывное число | Linear Regression (линейная регрессия), Ridge / Lasso (регрессия с регуляризацией), Polynomial Regression (полиномиальная), k-NN, Decision Tree, Random Forest, Gradient Boosting, SVR (опорные векторы для регрессии), нейросети | Цена квартиры, зарплата, спрос на товар |
| **Ranking (ранжирование)** | Порядок объектов по релевантности | LambdaMART, RankNet, бустинг с ranking loss | Выдача поисковика, лента товаров |

## 2. Unsupervised learning (обучение без учителя): ответов нет, модель ищет структуру сама

| Задача | Атрибут: что на выходе | Методы | Примеры |
|---|---|---|---|
| **Clustering (кластеризация)** | Группы похожих объектов, заранее не заданные | K-Means, Hierarchical (иерархическая), DBSCAN / HDBSCAN (по плотности), Gaussian Mixture (смесь гауссиан), Mean Shift, Spectral Clustering (спектральная) | Сегментация клиентов банка, группировка новостей |
| **Dimensionality Reduction (снижение размерности)** | Те же данные в меньшем числе признаков | PCA (метод главных компонент), t-SNE, UMAP, LDA (линейный дискриминантный анализ, вообще-то он с учителем), Autoencoder (автоэнкодер) | Визуализация многомерных данных, сжатие признаков |
| **Anomaly Detection (поиск аномалий)** | Метка «нормальный / странный» | Isolation Forest (изолирующий лес), One-Class SVM, LOF (локальный фактор выброса), автоэнкодер по ошибке восстановления | Мошеннические транзакции, поломка оборудования |
| **Association Rules (ассоциативные правила)** | Правила вида «если A, то часто B» | Apriori, FP-Growth | «С пивом покупают чипсы» |

## 3. Reinforcement learning (обучение с подкреплением): агент действует и получает награду

| Задача | Атрибут: что на выходе | Методы | Примеры |
|---|---|---|---|
| **Control / Decision making (управление и принятие решений)** | Стратегия действий (policy, политика) | Q-learning, SARSA, DQN (глубокий Q-learning), Policy Gradient, PPO, Actor-Critic, MCTS (поиск по дереву Монте-Карло) | Игры (го, шахматы, Atari), роботы, **дообучение LLM на отзывах людей (RLHF)** |

## 4. Задачи глубокого обучения: по типу данных

Здесь главное, что тебя путало. Эти задачи **не отдельная ветка**, а те же три ветки, только применённые к картинкам, звуку и тексту. Под капотом это почти всегда supervised.

| Задача | Атрибут: вход, выход | Методы / архитектуры | Примеры |
|---|---|---|---|
| **Image Classification (классификация изображений)** | Картинка → класс | CNN (свёрточные сети): ResNet, EfficientNet; ViT (визуальный трансформер) | Кот / собака, рентген |
| **Object Detection (детекция объектов)** | Картинка → рамки + классы | YOLO, Faster R-CNN, DETR | Машины на камере, люди в кадре |
| **Segmentation (сегментация)** | Картинка → класс для каждого пикселя | U-Net, Mask R-CNN, DeepLab, SAM | Отделить опухоль на снимке, фон от человека |
| **Face Recognition (распознавание лиц)** | Лицо → **вектор-эмбеддинг**, дальше сравнение расстояний | CNN + Triplet Loss (тройная функция потерь), ArcFace, FaceNet | Разблокировка телефона, поиск человека по фото |
| **ASR, Speech Recognition (распознавание речи)** | Звук → текст | RNN / LSTM, CTC loss, Transformer, Whisper, wav2vec | Субтитры, голосовые ассистенты |
| **TTS, Text-to-Speech (синтез речи)** | Текст → звук | Tacotron 2, FastSpeech, VITS, **vocoder (вокодер)**: HiFi-GAN, WaveNet | Озвучка, **восстановление голоса** |
| **NLP: Text Classification (классификация текста)** | Текст → класс | TF-IDF + логрегрессия, LSTM, BERT | Тональность отзыва, тематика письма |
| **Seq2Seq: Machine Translation (машинный перевод)** | Последовательность → последовательность | Encoder-Decoder (кодировщик-декодировщик), Transformer, T5 | Перевод, суммаризация |
| **Generative models (генеративные модели)** | Шум или подсказка → новый объект | GAN (генеративно-состязательные сети), VAE (вариационный автоэнкодер), Diffusion (диффузионные модели), LLM (GPT, Claude) | Генерация картинок, текста, музыки |
| **Time Series Forecasting (прогноз временных рядов)** | Прошлое ряда → будущие значения | ARIMA, Prophet, бустинг на лаговых признаках, LSTM, Temporal Fusion Transformer | Продажи, курс, нагрузка на сервер |
| **Recommender Systems (рекомендательные системы)** | Пользователь → список товаров | Collaborative Filtering (коллаборативная фильтрация), Matrix Factorization (матричная факторизация), two-tower нейросети | «Вам может понравиться» |
