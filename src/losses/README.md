# ROADMAP-LOSS-FUNCTION


## 1. Regression (регрессия): ответ — число

| Loss (функция потерь) | Идея / формула | Модели и методы | Особенность |
|---|---|---|---|
| **MSE, Mean Squared Error (среднеквадратичная ошибка)** | среднее от (y − ŷ)² | Линейная регрессия, Ridge, нейросети, бустинг | **Стандарт по умолчанию.** Квадрат сильно наказывает большие ошибки, поэтому чувствителен к выбросам |
| **MAE, Mean Absolute Error (средняя абсолютная ошибка)** | среднее от \|y − ŷ\| | Регрессия на грязных данных, бустинг | Все ошибки наказываются пропорционально, **устойчив к выбросам**. Производная в нуле не определена |
| **Huber Loss (функция Хьюбера)** | Мелкие ошибки как MSE, крупные как MAE | Робастная регрессия, RL (в DQN) | Компромисс: гладкая как MSE, устойчивая как MAE. Есть параметр порога δ |
| **RMSE (корень из MSE)** | √MSE | Чаще как метрика, чем как loss | Та же MSE, но в единицах ответа: ошибка «в рублях», а не «в рублях в квадрате» |
| **Quantile Loss (квантильная функция потерь)** | Несимметрично штрафует недо- и перепрогноз | Прогноз спроса, интервалы предсказания | Можно предсказывать не среднее, а, например, «с запасом» |
| **MAPE (средняя абсолютная процентная ошибка)** | среднее от \|y − ŷ\| / \|y\| | Временные ряды, бизнес-прогнозы | Ошибка в процентах. Ломается, когда y близок к нулю |

## 2. Classification (классификация): ответ — класс

| Loss (функция потерь) | Идея / формула | Модели и методы | Особенность |
|---|---|---|---|
| **Log Loss / Binary Cross-Entropy (бинарная кросс-энтропия)** | −[y·log(p) + (1−y)·log(1−p)] | **Логистическая регрессия**, нейросети с сигмоидой, бустинг | Два класса. Сильнее всего штрафует уверенную ошибку |
| **Categorical Cross-Entropy (категориальная кросс-энтропия)** | −Σ y_k · log(p_k) | Нейросети с softmax: CNN, трансформеры, LLM | То же самое для многих классов. **Самая используемая функция в глубоком обучении** |
| **Hinge Loss (кусочно-линейная функция потерь)** | max(0, 1 − y·ŷ), где y = ±1 | **SVM (метод опорных векторов)** | Штрафует не только ошибки, но и правильные ответы, лежащие слишком близко к границе. Требует «запас» (margin, отступ) |
| **Focal Loss (фокальная функция потерь)** | Кросс-энтропия с множителем (1−p)^γ | Детекция объектов (RetinaNet), несбалансированные классы | Приглушает лёгкие примеры, **заставляет учиться на трудных**. Спасает, когда одного класса в 100 раз больше |
| **Weighted Cross-Entropy (взвешенная кросс-энтропия)** | Кросс-энтропия с весом для каждого класса | Медицина, фрод, редкие классы | Ошибка на редком классе стоит дороже |
| **Gini / Entropy (критерий Джини / энтропия)** | Мера «перемешанности» классов в узле | **Деревья решений, случайный лес** | Не градиентный спуск, а критерий выбора разбиения: дерево ищет вопрос, после которого группы чище |

## 3. Ranking и Metric Learning (ранжирование и обучение расстояний): ответ — порядок или вектор

| Loss (функция потерь) | Идея / формула | Модели и методы | Особенность |
|---|---|---|---|
| **Pairwise Loss (попарная функция потерь)** | Штраф, если менее релевантный объект оказался выше | RankNet, LambdaMART, поисковики | Смотрит не на объект, а на пару: «кто должен быть выше» |
| **Contrastive Loss (контрастивная функция потерь)** | Похожие пары тянет друг к другу, разные отталкивает минимум на margin | Сиамские сети, сравнение подписей | Учит расстояния, а не классы |
| **Triplet Loss (тройная функция потерь)** | d(якорь, позитив) − d(якорь, негатив) + margin → вниз | **FaceNet, распознавание лиц** | Тройка: якорь, такой же, чужой. «Свой ближе чужого с запасом» |
| **ArcFace / CosFace (угловые функции потерь)** | Кросс-энтропия с отступом по углу между векторами | Современное распознавание лиц | Сильнее Triplet Loss на практике, не нужен подбор троек |
| **InfoNCE (контрастивная функция для многих негативов)** | Кросс-энтропия: найти «свою пару» среди многих чужих | CLIP, SimCLR, self-supervised learning (самообучение) | Основа обучения без разметки на картинках и тексте |

## 4. Сегментация, генерация, звук

| Loss (функция потерь) | Идея / формула | Модели и методы | Особенность |
|---|---|---|---|
| **Dice Loss (функция потерь Дайса)** | 1 − 2·\|пересечение\| / (\|A\| + \|B\|) | **U-Net**, медицинская сегментация | Меряет перекрытие масок. Хорошо работает, когда объект маленький, а фон огромный |
| **IoU / Jaccard Loss (функция Жаккара)** | 1 − пересечение / объединение | Сегментация, детекция рамок | Близкий родственник Dice |
| **Reconstruction Loss (ошибка восстановления)** | MSE или MAE между входом и выходом | **Автоэнкодеры**, поиск аномалий | Учит сжать и восстановить. Большая ошибка восстановления = аномалия |
| **KL Divergence (расхождение Кульбака–Лейблера)** | Насколько одно распределение отличается от другого | **VAE**, дистилляция моделей, RLHF | Сравнивает не числа, а распределения вероятностей |
| **Adversarial Loss (состязательная функция потерь)** | Генератор пытается обмануть дискриминатор, тот учится не обманываться | **GAN**, HiFi-GAN-вокодеры | Две сети учатся друг против друга |
| **Diffusion Loss (функция потерь диффузии)** | MSE между добавленным шумом и предсказанным шумом | Stable Diffusion, генерация картинок | Модель учится «угадывать шум», а не картинку |
| **CTC Loss (Connectionist Temporal Classification)** | Суммирует все варианты выравнивания звука и текста | **Распознавание речи (ASR)**, OCR | Не нужно размечать, какая буква в какой момент звучит |
| **Mel-spectrogram Loss (ошибка по мел-спектрограмме)** | MAE или MSE между спектрограммами | **TTS**: Tacotron, FastSpeech, VITS | Сравнивает «картинку звука», а не сам сигнал |
