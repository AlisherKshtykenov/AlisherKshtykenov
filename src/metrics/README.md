# ROADMAP-METRICS


## 1. Regression (регрессия): ответ — число

| Metric (метрика) | Идея | Диапазон | Особенность |
|---|---|---|---|
| **MAE (средняя абсолютная ошибка)** | Средняя ошибка в единицах ответа | 0..∞, меньше лучше | **Самая понятная**: «ошибаемся в среднем на 50 тысяч» |
| **MSE (среднеквадратичная ошибка)** | Средняя ошибка в квадрате | 0..∞, меньше лучше | Сильно чувствует большие промахи. Единицы в квадрате, читать неудобно |
| **RMSE (корень из MSE)** | √MSE | 0..∞, меньше лучше | Как MSE, но в нормальных единицах |
| **R² (коэффициент детерминации)** | Насколько модель лучше, чем просто угадывать среднее | −∞..1, больше лучше | 1 — идеально, 0 — не лучше среднего, минус — хуже среднего |
| **MAPE (средняя процентная ошибка)** | Ошибка в процентах | 0..∞ %, меньше лучше | Удобна для бизнеса. Ломается, когда ответы около нуля |

## 2. Classification (классификация): ответ — класс

Всё строится на **Confusion Matrix (матрица ошибок)**: четыре клетки. TP — сказали «да», и правда да. TN — сказали «нет», и правда нет. FP — сказали «да», а было нет (ложная тревога). FN — сказали «нет», а было да (пропуск).

| Metric (метрика) | Идея | Диапазон | Особенность |
|---|---|---|---|
| **Accuracy (доля правильных)** | (TP + TN) / все | 0..1 | **Обманывает при несбалансированных классах**: если 99% писем не спам, модель «всегда не спам» даёт 99% |
| **Precision (точность)** | TP / (TP + FP): из тех, кого назвали «да», сколько правда «да» | 0..1 | Важна, когда **ложная тревога дорогая**: спам-фильтр не должен прятать нужные письма |
| **Recall (полнота)** | TP / (TP + FN): из всех настоящих «да», сколько нашли | 0..1 | Важна, когда **пропуск дорогой**: не пропустить болезнь, мошенника |
| **F1-score (F1-мера)** | Гармоническое среднее Precision и Recall | 0..1 | Баланс двух. **Стандарт для несбалансированных классов** |
| **Specificity (специфичность)** | TN / (TN + FP): из всех «нет», сколько правильно отсеяли | 0..1 | Пара к Recall, в медицине |
| **Balanced Accuracy (сбалансированная доля правильных)** | Среднее Recall по каждому классу | 0..1 | Accuracy, которая не обманывается дисбалансом |
| **MCC (коэффициент корреляции Мэтьюса)** | Учитывает все четыре клетки сразу | −1..1 | Самая честная одна цифра для двух классов |
| **ROC-AUC (площадь под ROC-кривой)** | Насколько хорошо модель ставит «да» выше «нет» при любых порогах | 0,5..1 | 0,5 — монетка, 1 — идеально. Не зависит от порога 0,5 |
| **PR-AUC (площадь под кривой точность–полнота)** | Как ROC-AUC, но через Precision и Recall | 0..1 | **Лучше ROC-AUC при сильном дисбалансе** |

Для многих классов те же метрики считают по каждому классу и усредняют: **macro** (все классы поровну), **micro** (все примеры поровну), **weighted** (по размеру класса).

## 3. Ranking (ранжирование): ответ — порядок

| Metric (метрика) | Идея | Диапазон | Особенность |
|---|---|---|---|
| **Precision@K (точность в топ-K)** | Сколько из первых K результатов релевантны | 0..1 | «Из первых 10 ссылок сколько полезных» |
| **Recall@K (полнота в топ-K)** | Какую долю всех релевантных нашли в первых K | 0..1 | Для рекомендаций: «нашли ли нужное в первых 20» |
| **MAP (средняя точность)** | Precision, усреднённый по позициям каждого релевантного результата | 0..1 | Учитывает, **насколько высоко** стоят хорошие результаты |
| **MRR (средний обратный ранг)** | 1 / позиция первого правильного ответа | 0..1 | Когда важен только первый правильный: поиск ответа на вопрос |
| **NDCG (нормализованный дисконтированный выигрыш)** | Релевантность с понижением за низкую позицию | 0..1 | **Стандарт для поисковиков**. Умеет степени релевантности, а не только да/нет |

## 4. Clustering (кластеризация): ответ — группы

| Metric (метрика) | Идея | Диапазон | Особенность |
|---|---|---|---|
| **Silhouette (силуэт)** | Насколько точка ближе к своему кластеру, чем к соседнему | −1..1, больше лучше | **Не нужны правильные ответы.** Помогает выбрать число кластеров в K-Means |
| **Davies–Bouldin (индекс Дэвиса–Болдина)** | Отношение разброса внутри кластеров к расстоянию между ними | 0..∞, меньше лучше | Тоже без правильных ответов |
| **Calinski–Harabasz (индекс Калински–Харабаза)** | Разброс между кластерами / разброс внутри | 0..∞, больше лучше | Быстрый, без правильных ответов |
| **ARI (скорректированный индекс Рэнда)** | Насколько кластеры совпадают с настоящими классами | −1..1 | **Нужны правильные ответы**, если они есть для проверки |
| **NMI (нормализованная взаимная информация)** | Сколько общей информации у кластеров и настоящих классов | 0..1 | Тоже с правильными ответами |

## 5. Vision (детекция и сегментация)

| Metric (метрика) | Идея | Диапазон | Особенность |
|---|---|---|---|
| **IoU (пересечение над объединением)** | Площадь пересечения / площадь объединения | 0..1 | Насколько рамка или маска совпала с настоящей |
| **Dice (коэффициент Дайса)** | 2 · пересечение / сумма площадей | 0..1 | Родственник IoU, **стандарт в медицинской сегментации** |
| **mAP (средняя точность для детекции)** | Precision–Recall по всем классам и порогам IoU | 0..1 | **Главная метрика детекции**: YOLO, Faster R-CNN |

## 6. Generative (генерация текста и картинок)

| Metric (метрика) | Идея | Диапазон | Особенность |
|---|---|---|---|
| **Perplexity (перплексия)** | Насколько модель «удивлена» правильным текстом | 1..∞, меньше лучше | Для языковых моделей. Это экспонента от кросс-энтропии |
| **BLEU (блю)** | Сколько кусков слов совпало с эталонным переводом | 0..1 | **Машинный перевод** |
| **ROUGE (руж)** | Сколько слов из эталона попало в ответ | 0..1 | **Суммаризация** |
| **FID (расстояние Фреше)** | Насколько статистика сгенерированных картинок похожа на настоящие | 0..∞, меньше лучше | **Стандарт для GAN и диффузии** |

## 7. Audio (речь)

| Metric (метрика) | Идея | Диапазон | Особенность |
|---|---|---|---|
| **WER (доля ошибок по словам)** | (замены + вставки + пропуски слов) / число слов | 0..∞, меньше лучше | **Главная метрика распознавания речи** |
| **CER (доля ошибок по символам)** | То же по буквам | 0..∞, меньше лучше | Для языков без пробелов и для коротких слов |
| **MOS (средняя оценка мнения)** | Люди слушают и ставят оценку от 1 до 5 | 1..5, больше лучше | **Главная метрика синтеза речи**. Субъективная, но другой честной пока нет |
